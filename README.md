次に、プログラムを実行する際は、使用するデータセットやネットワークモデルに応じて、学習回数（EPOC）、バッチサイズ（BS）、学習率（ETA・BETA）、NETMODEL、学習データ数・テストデータ数などの各パラメータを事前に確認・調整してから実行してください。

データセットの切り替えについては、「DxDeepLearnYY.cpp」の22行目～28行目がoptdigitsデータセット、30行目～40行目が手書き文字MNISTデータセット、42行目～50行目がCIFAR10データセットとなっています。使用したいデータセットのコメントアウトを外して使用します。それと同時に「MLPyy.h」にてデータセットに応じた出力クラス数（K）、入力データの次元数（IND）、最大ノード数（NMAX）、入力チャンネル数（ICH）、画像サイズ（H・W）、入力層のカーネルサイズ（IKS）を設定するパラメータがあります。26行目～32行目がoptdigitsデータセット、34行目～40行目が手書き文字MNISTデータセット、42行目～48行目がCIFAR10データセットとなっています。

最後に「DxDeepLearnYY.cpp」のMLP関数内にてExcelファイルに記録する処理がある。「LogFile」,「LogBFile」をプロジェクトのフォルダ内で作成しないとエラーが発生するため注意してください。
